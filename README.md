# Pashu360

### AI-powered early-warning and adaptive voice-triage system for livestock health
SIH26128 | Kurien Vision

## Problem

Livestock health issues can develop before obvious clinical signs appear.
Farmers may also face limited veterinary access and fragmented health records.

## Our Solution

Pashu360 is an offline-first livestock health platform that maintains
animal-specific health records and baselines, monitors changes in milk
yield and health indicators, and uses AARVI for adaptive voice-based
triage.

### Core Workflow

Animal Health Passport
        ↓
Continuous Monitoring
        ↓
Baseline Deviation
        ↓
AARVI Adaptive Triage
        ↓
Explainable Risk
        ↓
Para-Vet Referral
        ↓
District-Level Surveillance

## AARVI

AARVI is an adaptive voice-triage system.

It does not unnecessarily ask the farmer a long list of questions.
When monitored indicators such as milk yield deviate from the animal's
expected baseline, AARVI initiates relevant questions and adapts the
next question according to the farmer's responses.

## Key Features

- Animal-specific health passport
- Individual milk-yield baseline
- Offline-first farmer workflow
- Multilingual voice interaction
- Adaptive AARVI triage
- Explainable risk scoring
- Para-vet referral workflow
- Government/district surveillance dashboard
